# Сайт Atava CRM

Статический сайт из пяти страниц: чистый HTML, CSS и JavaScript, без фреймворков и сборки. Тексты правятся прямо в HTML-файлах.

```
site/                    ← эту папку целиком загружаете на хостинг
  index.html             главная            /
  tarify/index.html      тарифы             /tarify/
  kejsy/index.html       кейсы              /kejsy/
  politika/index.html    политика           /politika/
  spasibo/index.html     спасибо за заявку  /spasibo/  (закрыта от поиска)
  404.html               страница «не найдено»
  assets/site.css        все стили; цвета и шрифты — в начале файла (:root)
  assets/site.js         скрипт; НАСТРОЙКИ — в самом начале файла
  assets/fonts/          шрифты Geologica и Manrope (кириллица + латиница)
  assets/img/            логотипы, картинка для соцсетей og.png, иконки
  robots.txt, sitemap.xml, llms.txt, favicon.svg, site.webmanifest
priemnik/                ← приёмник заявок (Google Таблица + почта) и инструкция
```

## 1. Перед загрузкой: три замены

| Что | Где искать | На что заменить |
| --- | --- | --- |
| `[ДОМЕН]` | все `.html`, `sitemap.xml`, `robots.txt`, `llms.txt`, `priemnik/Code.gs` | домен без `https://`, например `atava.kg` |
| `ВСТАВЬТЕ_ID` | `assets/site.js` и три формы в `index.html`, `tarify/`, `kejsy/` | см. `priemnik/README.md` |
| `[EMAIL ДЛЯ ЗАЯВОК]` | `priemnik/Code.gs` | почта для заявок |

Удобнее всего — «Найти и заменить во всех файлах» в VS Code или Notepad++ (папка `site`).

## 2. Как выложить сайт
1. Скопируйте **содержимое** папки `site` в корень сайта на хостинге (туда, где должен лежать `index.html`).
2. Настройте хостинг так, чтобы несуществующие адреса отдавали `404.html` (в панели хостинга: «страница ошибки 404»; для Apache — строка `ErrorDocument 404 /404.html` в `.htaccess`; Netlify, Cloudflare Pages и GitHub Pages подхватывают `404.html` сами).
3. Включите HTTPS и сжатие gzip/brotli (в большинстве панелей — галочка).

Сайт рассчитан на размещение в корне домена: ссылки вида `/tarify/` не заработают, если положить его в подпапку.

## 3. Где что меняется

**Настройки в `assets/site.js` (самый верх файла):**
- `ENDPOINT` — адрес приёмника заявок;
- `WHATSAPP` — номер только цифрами (`996700123456`). Пока пусто, плавающая кнопка WhatsApp и кнопки на странице «Спасибо» скрыты;
- `WA_TEXT` — готовый текст сообщения в WhatsApp;
- `PHONE` — телефон для подвала (`+996 700 123 456`);
- `PROMO_END` — окончание акции. После этой даты сайт сам скрывает верхнюю полосу, акционную кнопку на тарифах, акционные цены на главной и фразы про скидку −30%;
- `GA_ID`, `YM_ID`, `META_PIXEL_ID` — счётчики Google Analytics, Яндекс Метрики и пиксель Meta. Пустое значение — счётчик не подключается. События: `lead_submit` (заявка отправлена, срабатывает на странице «Спасибо»), `whatsapp_click`.

**Цены.** Цены написаны текстом в HTML:
- `tarify/index.html` — три карточки, у каждой три набора цен (`data-set="month"`, `"year"`, `"promo"`), таблица сравнения, вопросы. Ответы на вопросы продублированы в блоке `FAQPage` в начале файла — меняйте в обоих местах слово в слово;
- `index.html` — блок «Тарифы» (акционная и обычная цена) и абзац «Коротко об Atava»;
- в начале каждого из этих файлов — блок `application/ld+json` с ценами для поисковиков (`"price":"13000"`);
- `llms.txt` — описание для ИИ-ассистентов;
- строка «Цены актуальны на …» на странице тарифов.

**После окончания акции** поменяйте вручную ещё заголовок страницы тарифов (`<title>` с «от 9 100 сом») и ответ «Что такое кастомизация и 5 часов в подарок?» вместе с его копией в `FAQPage`.

**Почта заявок** — `EMAIL_TO` в `Code.gs` (после правки сделайте новую версию развёртывания, см. `priemnik/README.md`).

## 4. Как добавить отзыв или кейс
- **Отзыв:** в `index.html` найдите комментарий «Чтобы добавить отзыв» в блоке отзывов — там готовый шаблон. Раскомментируйте, впишите текст, имя, должность, компанию.
- **Кейс:** в `kejsy/index.html` скопируйте блок `<article>…</article>` первого кейса и поменяйте теги, заголовок, цифры, тексты и цитату.
- Разметку `Review` и `AggregateRating` для поисковиков добавляйте только с настоящими отзывами, где есть имена.

## 5. Поисковики: Google Search Console и Яндекс Вебмастер
**Google:**
1. Откройте [search.google.com/search-console](https://search.google.com/search-console) → «Добавить ресурс» → «Домен» → введите домен.
2. Google покажет TXT-запись — добавьте её в DNS у регистратора домена и нажмите «Подтвердить» (запись может появиться через 10–60 минут).
3. Слева «Файлы Sitemap» → введите `sitemap.xml` → «Отправить».

**Яндекс:**
1. Откройте [webmaster.yandex.ru](https://webmaster.yandex.ru) → «Добавить сайт» → `https://ваш-домен`.
2. Выберите подтверждение «Мета-тег» — скопируйте строку `<meta name="yandex-verification" …>` и вставьте её в `<head>` файла `index.html` сразу после строки `<meta name="viewport" …>`. Загрузите файл на хостинг и нажмите «Проверить».
3. «Индексирование → Файлы Sitemap» → добавьте `https://ваш-домен/sitemap.xml`.

Проверка разметки: [search.google.com/test/rich-results](https://search.google.com/test/rich-results) и [validator.schema.org](https://validator.schema.org) — вставьте адрес страницы после публикации.

Список — в `ОТЧЁТ.md`, раздел «Что ждёт ответа заказчика».

## Превью для согласования (Vercel)

Сейчас сайт закрыт от индексации: `site/robots.txt` запрещает всё, а `vercel.json` в корне проекта отдаёт заголовок `X-Robots-Tag: noindex`.
Перед запуском на боевом домене: заменить `site/robots.txt` содержимым `robots.production.txt` и удалить блок `headers` с `X-Robots-Tag` из корневого `vercel.json` (строки `outputDirectory: "site"` не трогать – они говорят Vercel, что сайт лежит в папке site).
Vercel: Root Directory – `site`, Framework Preset – `Other`, сборка не нужна.
