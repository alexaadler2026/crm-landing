# Как подключить приём заявок (15 минут, без программиста)

Заявки с сайта будут попадать строкой в Google Таблицу и приходить письмом на почту. Таблицу можно открыть в Excel: «Файл → Скачать → Microsoft Excel (.xlsx)».

## 1. Создайте таблицу
1. Откройте [sheets.google.com](https://sheets.google.com) под аккаунтом компании и создайте пустую таблицу. Назовите её, например, «Заявки Atava».
2. В меню выберите **Расширения → Apps Script**. Откроется редактор кода.

## 2. Вставьте код
1. Удалите всё, что есть в файле `Code.gs` в редакторе.
2. Откройте файл `Code.gs` из этой папки, скопируйте всё и вставьте в редактор.
3. В строках 9–10 впишите свои данные:
   - `EMAIL_TO` — почта, куда присылать заявки, например `'sales@atava.kg'`;
   - `SITE_URL` — адрес сайта, например `'https://atava.kg'`.
4. Нажмите значок дискеты (**Сохранить**).

## 3. Дайте разрешения
1. Вверху в списке функций выберите `setup` и нажмите **Выполнить**.
2. Google попросит доступ к таблице и почте: выберите свой аккаунт → «Дополнительные настройки» → «Перейти к проекту» → **Разрешить**. Так бывает у всех скриптов, которые пишете вы сами.
3. В таблице появится лист «Заявки» со столбцами: Дата и время, Имя, Телефон, Отрасль, Тариф, Страница, utm_source, utm_medium, utm_campaign, utm_content, utm_term, Источник перехода, Статус.

## 4. Опубликуйте приёмник
1. Нажмите **Начать развертывание → Новое развертывание**.
2. Тип — **Веб-приложение**. «Запуск от имени» — **Я**. «У кого есть доступ» — **Все**.
3. Нажмите **Начать развертывание** и скопируйте **URL веб-приложения** (заканчивается на `/exec`).

## 5. Впишите адрес на сайт
Замените `https://script.google.com/macros/s/ВСТАВЬТЕ_ID/exec` на скопированный адрес в четырёх местах:
- `assets/site.js` — строка `ENDPOINT:` (главное место, его использует скрипт);
- `index.html`, `tarify/index.html`, `kejsy/index.html` — атрибут `action` у формы (нужен, только если в браузере посетителя не работает JavaScript).

Проще всего — «Найти и заменить во всех файлах» в любом редакторе (Notepad++, VS Code) по строке `ВСТАВЬТЕ_ID`.

## 6. Проверьте
Отправьте по одной заявке с главной, тарифов и кейсов. В таблице должны появиться три строки, на почту — три письма с темой «Заявка на демо Atava: имя, отрасль».

## Если что-то не так
- **Строки появляются, писем нет** — проверьте `EMAIL_TO` и папку «Спам». Бесплатный Google-аккаунт отправляет до 100 писем в сутки.
- **Изменили код** — после правки нужно **Развертывание → Управление развертываниями → карандаш → Версия: новая → Развернуть**. Адрес при этом не меняется.
- **Столбец «Статус»** заполняет менеджер вручную: «перезвонили», «демо назначено», «отказ» и т. п.
